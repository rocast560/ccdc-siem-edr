CCDC-EDR Console

Five screens and an interface system for the browser-only EDR/SIEM console - a dense analyst instrument for reading synthetic Sysmon, Windows Event, auditd and Zeek telemetry, and writing detection rules against it.

Screens
6 artboards
Frame
1600 × 1000
Fidelity
Static hi-fi

Design basis. Dark tokens come from Blueprint, Palantir's open-source design system - surfaces #0f1113 → #3f444d, 2 px radius, 24/26 px controls, the intent ramp. The screen architecture is the dense analyst-console idiom: navbar → context toolbar → up to three work regions → status bar. No proprietary Gotham screen, workflow or branding is reproduced. Every hostname, address, hash and timestamp below is invented sample data from the plan's synthetic scenarios.

01 Dashboard Severity counts, ingest volume against the intrusion window, and the correlated kill chain as the standing right-rail object. The scenario selector and the drop target both live in the context toolbar, because loading data is the first thing an analyst does.

Havoc HIGH PREVALENCE agent: Demon
Open-source post-exploitation framework. The Demon agent leans on indirect syscalls, sleep obfuscation (Ekko) and return-address spoofing, so user-mode API hooking sees little. Detection value concentrates in memory-allocation shape, thread creation without a matching stub, and the timing regularity of its default HTTP listener.
